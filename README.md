# MG · AChR-MG 发病机制分子动画项目

本仓库整理**乙酰胆碱受体抗体阳性重症肌无力（acetylcholine receptor antibody-positive myasthenia gravis, AChR-MG）**的发病机制，并把它转化为可用于制作 **5 分钟医学科普分子动画**的科学文稿和分镜脚本，面向医学生与基础医学研究者。

## 仓库内容

| 文件 | 说明 |
|---|---|
| [`docs/AChR-MG_发病机制_动画文稿.md`](docs/AChR-MG_发病机制_动画文稿.md) | 机制文稿：正常神经肌肉接头传递、三条抗体致病机制、MuSK-MG 对比、病理结局；附 PubMed 检索词与【需要文献验证】清单 |
| [`docs/AChR-MG_分子动画分镜脚本_5min.md`](docs/AChR-MG_分子动画分镜脚本_5min.md) | 5 分钟分镜脚本：34 个镜头，含画面、旁白、字幕、备注，以及配色规范和制作注意事项 |

## 动画叙事线

正常神经肌肉接头传递 → 自身抗体出现 → 三条致病机制（阻断结合位点 · 交联内化降解 · 补体破坏突触后膜）→ 安全系数下降与肌无力 → 波动性肌无力 → MuSK-MG 差异

## 科学准确性原则

- 专业名词首次出现时标注中英文全称与缩写；
- 动画旁白与画面只采用学界共识内容；存在争议或待核实的内容在文稿中标注【需要文献验证】，不进入动画；
- 欢迎通过 Issue 提交勘误和文献补充。
