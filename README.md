# MG · AChR-MG 发病机制分子动画项目

本仓库用于整理**乙酰胆碱受体抗体阳性重症肌无力（AChR antibody-positive myasthenia gravis, AChR-MG）**的发病机制，并将其编写为可直接改编成**分子动画**的科学文稿。

## 项目目标

- 以"**空间位置 → 参与分子 → 动态先后 → 结果**"的分镜逻辑，描述神经肌肉接头（NMJ）从正常传递到抗体介导损伤的全过程；
- 为医学生与基础医学研究者提供准确、可追溯、便于可视化的机制底稿；
- 对存在学术争议或数据不确定的内容统一标注【需要文献验证】，不引入未经证实的假说。

## 内容结构

| 文件 | 内容 |
|---|---|
| [`docs/AChR-MG_发病机制_动画文稿.md`](docs/AChR-MG_发病机制_动画文稿.md) | 主文稿 |

主文稿分为四部分：

1. **正常 NMJ 信号传递**：ACh 合成、释放、结合 AChR、终板电位、肌肉动作电位与信号终止；
2. **AChR 抗体三条核心致病机制**：阻断 ACh 结合、AChR 交联内化降解、经典补体激活与 MAC 破坏突触后膜；
3. **MuSK-MG 与 AChR-MG 对比**：IgG4 与 IgG1/3、信号干扰与补体破坏的差异；
4. **病理结局**：安全系数下降 → 肌无力与易疲劳/波动性的对应关系。

附录包括 PubMed 检索关键词清单与【需要文献验证】条目汇总。

## 适用读者

医学生、神经免疫及基础医学研究者、科学动画/可视化制作者。
