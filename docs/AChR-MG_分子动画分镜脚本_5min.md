**表格使用说明**
- **时长**：第一行为镜头时长，第二行为全片时间码。
- **画面描述**：分为"镜头 / 动态 / 配色"三项，可直接作为动画制作说明或 AI 视频提示词的基础。
- **旁白**：按约 3–3.8 字/秒的平缓语速设计。
- **底部字幕**：精简版旁白，与旁白逐句对应，每镜不超过 2 行。
- **备注**：科学要点、易错点、拆镜建议。

## 二、配色规范

### 2.1 统一配色（按约定，不可更改）

| 元素 | 颜色 | 建议 HEX | 造型要点 |
|---|---|---|---|
| 突触前膜（神经末梢及突触小泡） | 浅蓝 | `#A9D4F5` | 末梢为光滑膜；小泡为半透明浅蓝球，内装 ACh |
| 乙酰胆碱（ACh） | 橙色小球 | `#F5922F` | 实心小球，带高光；水解碎片用浅橙 |
| 烟碱型乙酰胆碱受体（AChR） | 绿色跨膜蛋白 | `#3FAF62` | 五亚基"玫瑰花结"，贯穿膜，胞外段伸入间隙 |
| IgG 自身抗体 | 红色 Y 型 | `#D62839` | 两条 Fab 臂 + 一条 Fc 尾，比例接近等长 |
| 补体复合物 | 紫色 | C1q `#B9A2E3`（浅紫）<br>C3b `#8F63CC`（中紫）<br>MAC `#5B2E91`（深紫） | C1q 为"六头花束"；C3b 为碎片；膜攻击复合物（MAC）为环状孔道 |
| 突触后膜 | 浅灰色褶皱肌膜 | `#C8CDD3` | 梳齿状褶皱：顶端为嵴顶，底部为谷底 |

## 四、动画制作注意事项清单

### A. 科学准确性

- [ ] **A1 比例与时间**：片头或角标注明"示意图，非等比例"；毫秒、微秒级事件一律慢放，并加"慢放"角标。
- [ ] **A2 空间方位固定**（最易出错，逐镜核对）：
  - AChR 集中于褶皱嵴顶，Nav1.4 集中于谷底；神经末梢活性区对准褶皱开口。
  - AChR 胞外段伸入突触间隙；ACh 结合口袋在 α/ε、α/δ 亚基交界的侧面，不在顶端；MIR 在 α 亚基顶端外侧。
  - IgG 用 Fab 臂（Y 的两臂）结合抗原，Fc（Y 的尾）朝向间隙；补体从 Fc 端起始；MAC 插在突触后肌膜上，不在神经末梢。
  - AChE 锚定在基底膜上，不漂浮、不附着在受体上。
- [ ] **A3 三条机制的视觉边界**：机制①只"盖住"受体，不减少受体、不破坏膜；机制②不出现补体（紫色）；紫色只在机制③出现；MuSK 段全程不出现紫色。
- [ ] **A4 不画、不讲的内容**（目前缺乏共识，对应机制文稿附录 B）：
  - 一个 IgG 两臂结合同一受体的两个 α 亚基；
  - 网格蛋白介导的内吞；
  - 把 Fc 六聚体平台当作定论；
  - 三条机制的权重排序或百分比；
  - 具体的降解加速倍数、抗体阳性率等未核实数值；
  - MuSK 抗体对 ColQ–AChE 锚定或突触前的影响；
  - 眼外肌易感机制、冰袋试验机制、晨轻暮重的独立昼夜节律机制。
- [ ] **A5 专业审核**：定稿前请神经肌肉病或神经免疫方向的专业人员审核，并对照机制文稿的【需要文献验证】清单复核。

### B. 视觉与配色

- [ ] **B1** 严格执行第二部分配色表：红色只给 IgG（含 MIR 提示描边），紫色只给补体。
- [ ] **B2 色觉障碍友好**：红色 IgG 与绿色 AChR 对红绿色弱观众难以区分，须同时靠**形状**（Y 形 vs 五聚体环）、**明度**（红色偏深、绿色偏亮）和**描边**区分；关键帧用色盲模拟工具检查。
- [ ] **B3 尺寸数量级参考**（用于把握相对比例，非精确值）：

  | 结构 | 数量级 | 动画处理 |
  |---|---|---|
  | ACh 分子 | < 1 nm | 需大幅放大才能看见 |
  | AChR 直径 | 约 8 nm | 作为基准尺寸 |
  | IgG | 约 10–15 nm | 与 AChR 同一量级，不要画得远大于受体 |
  | MAC 孔道内径 | 约 10 nm | 与受体同一量级 |
  | 突触小泡 | 约 40–50 nm | 与间隙宽度相当 |
  | 初级突触间隙 | 约 50 nm | — |

- [ ] **B4 角色一致性**：为每个分子建立"角色设定图"（正视、侧视、顶视），全片复用同一模型和材质。
- [ ] **B5 情绪控制**：病理段落色调可偏冷、偏暗，但保持信息清晰；不使用爆炸、撕裂特写、惊悚音效等恐吓化表现。

### C. 旁白与字幕

- [ ] **C1 语速**：约 3–3.8 字/秒（全片旁白约 950 字）；镜头之间留 0.3–0.5 s 停顿；配音完成后按实际音频微调镜头时长，总时长控制在 5:00 ± 5 s。
- [ ] **C2 字幕**：不超过 2 行，每行尽量不超过 18 个汉字宽度；与旁白同进同出；离子符号使用上标（Ca²⁺、Na⁺）。
- [ ] **C3 读音统一**（真人配音或 TTS 均适用）：
  - "重症肌无力"的"重"读 zhòng；

- [ ] **C4 缩写**：缩写首次出现时，字幕给出中文全称和缩写（脚本中已处理）。

### D. AI 视频生成

- [ ] **D1 拆镜**：多数工具单次只能生成 5–10 s。S07、S26、S27、S29、S31 超过 10 s，按各镜备注拆分后再拼接。
